プライバシーポリシー

草崩し (Kusakuzushi) — 最終更新日: 2026年7月26日

English version below

1. 対象

本ポリシーは、個人開発者 toshi0607 が提供する以下の 2 つを対象とします。

  • Chrome 拡張「草崩し (Kusakuzushi)」
  • Web 版 kusakuzushi.toshi0607.com

2. Chrome 拡張が収集する情報

ありません。本拡張は、いかなる個人情報・利用状況・識別子も収集、保存、送信しません。

具体的には、本拡張は次のいずれも行いません。

  • 外部サーバーへの通信(ネットワークリクエストを一切行いません)
  • Cookie・localStorage・chrome.storage などへの保存
  • アクセス解析、広告、トラッキング、フィンガープリンティング
  • 閲覧履歴、入力内容、認証情報の読み取り
  • 収集した情報の第三者への販売・提供(そもそも収集しません)

拡張が行う処理

本拡張は https://github.com/* 上でのみ動作し、表示中のページに すでに描画されているコントリビューショングラフ(いわゆる「草」)の マス目の色の濃さと日付を、あなたのブラウザ内でのみ読み取ってゲームの盤面に変換します。 読み取った内容はブラウザの外に出ることはなく、ページを離れるかゲームを終了した時点で破棄されます。 ゲーム中に灰色になったマス目の見た目も一時的なもので、GitHub 上のデータは一切変更されません。

ホスト権限について

本拡張は GitHub のプロフィールページ上の草グラフに重ねて動作する必要があるため、 https://github.com/* へのアクセスを宣言しています。GitHub のユーザー名は 任意の文字列を取りうるため、プロフィールページだけを指す一致パターンを書くことができません。 この権限は上記のグラフの読み取りとゲーム画面の描画にのみ使用します。 GitHub 以外のサイトでは本拡張は一切動作しません。

3. Web 版が扱う情報

Web 版では、あなたが入力した GitHub のユーザー名を、 草グラフのデータを取得するために外部 API (github-contributions-api、 運営者: Jonathan Gruber)へ送信します。同 API の取り扱いについては当該提供者の方針に従います。

入力されたユーザー名やスコアを当方のサーバーに保存することはありません。 共有用の画像 (/share/) は、共有 URL に含まれるユーザー名とスコアから その都度生成し、配信のためのキャッシュにのみ一時的に保持します。

Web 版はアクセス解析ツール、広告、トラッキング用 Cookie を使用していません。 ホスティング事業者 (Cloudflare) が、サービス提供とセキュリティの目的で アクセスログを記録する場合があります。

4. 子どもの利用について

本サービスは個人情報を収集しないため、年齢を問わず安全にご利用いただけます。

5. 本ポリシーの変更

内容を変更する場合は、本ページを更新し、上部の最終更新日を改めます。 収集する情報の種類を増やす変更を行う場合は、変更前に本ページで告知します。

6. お問い合わせ

本ポリシーおよび本サービスに関するお問い合わせは github.com/toshi0607 までお願いします。

Privacy Policy (English)

Kusakuzushi — Last updated: July 26, 2026

1. Scope

This policy covers the Kusakuzushi Chrome extension and the web version at kusakuzushi.toshi0607.com, both published by the individual developer toshi0607.

2. Data collected by the Chrome extension

None. The extension does not collect, store, or transmit any personal information, usage data, or identifiers. It makes no network requests at all, writes nothing to cookies, localStorage, or chrome.storage, and contains no analytics, ads, tracking, or fingerprinting code.

The extension runs only on https://github.com/*. It reads the shade and date of the contribution-graph cells that GitHub has already rendered on the page, and converts them into a game board entirely within your browser. Nothing leaves your browser, and the data is discarded when you leave the page or stop the game. Cells that turn grey during play are a temporary visual effect only; no data on GitHub is modified.

Host permission: the extension needs to overlay the contribution graph on GitHub profile pages. Because GitHub usernames can be any string, no match pattern can target profile pages alone, so https://github.com/* is declared. The permission is used solely to read that graph and draw the game. The extension does not run on any other site.

3. Data handled by the web version

The web version sends the GitHub username you enter to a third-party API (github-contributions-api by Jonathan Gruber) in order to fetch the contribution graph. That provider's own policy applies to the request.

We do not store entered usernames or scores on our servers. Share images (/share/) are generated on demand from the username and score contained in the share URL, and are held only in a delivery cache.

The web version uses no analytics tools, no advertising, and no tracking cookies. Our hosting provider (Cloudflare) may record access logs for service operation and security.

4. Children

Because no personal information is collected, the service is safe to use at any age.

5. Changes to this policy

If this policy changes, this page is updated and the date above is revised. Any change that would expand the categories of data collected will be announced here before it takes effect.

6. Contact

Questions about this policy or the service: github.com/toshi0607.
